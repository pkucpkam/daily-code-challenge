# 670. Maximum Swap

**Difficulty:** Medium 🟡  
**Topics:** Math, Greedy  

---

## Problem Statement

You are given an integer `num`. You can swap two digits at most once to get the maximum valued number.

Return the maximum valued number you can get.

---

## Examples

### Example 1

```text
Input: num = 2736
Output: 7236
```

**Explanation:** Swap the number 2 and the number 7.

---

### Example 2

```text
Input: num = 9973
Output: 9973
```

**Explanation:** No swap.

---

## Constraints

- `0 <= num <= 10⁸`
