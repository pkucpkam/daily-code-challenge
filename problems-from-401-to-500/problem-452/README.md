# 633. Sum of Square Numbers

**Difficulty:** Medium

Given a non-negative integer `c`, decide whether there are two integers `a` and `b` such that:

$$a^2 + b^2 = c$$

## Examples

### Example 1

```text
Input: c = 5
Output: true
Explanation: 1 * 1 + 2 * 2 = 5
```

### Example 2

```text
Input: c = 3
Output: false
```

## Constraints

- $0 \leq c \leq 2^{31} - 1$
